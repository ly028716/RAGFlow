# RAG Agent 面试演示脚本（约 8 分钟）

## 演示前准备

1. 启动 MySQL、Redis、后端和前端，确认 `/docs` 与 `/agent` 可访问。
2. `.env` 配置为 DashScope：`qwen-plus` + `text-embedding-v3`。
3. 准备一个包含架构、检索与引用策略文档的知识库；用非所有者账号准备一个无权知识库作为权限对照。

## 演示流程

| 时间 | 操作 | 讲解重点 |
| --- | --- | --- |
| 0:00–0:45 | 展示系统架构图。 | 本地持久化语料与 Chroma，在线 DashScope 模型；边界清晰。 |
| 0:45–1:30 | 上传一个 Markdown/PDF 文档，等待处理。 | 说明解析、切分、Embedding 与 collection 隔离。 |
| 1:30–2:20 | 选择知识库，在普通 RAG 对话中提问。 | 展示 SSE 回答、来源和检索/生成耗时。 |
| 2:20–4:40 | 打开 `/agent`，选择同一知识库并执行同一问题。 | 依次讲解查询改写、检索、上下文选择和引用校验四阶段。 |
| 4:40–5:40 | 展开 Agent 时间线。 | 展示知识库范围、Top-K、阈值、原始/过滤片段、最终上下文、Token 与总耗时。 |
| 5:40–6:30 | 切换到无权知识库或尝试未授权 ID。 | 说明权限校验在检索前生效，来源不会泄露。 |
| 6:30–7:20 | 打开评测报告和固定题集。 | 说明 Recall@K、Hit Rate、Faithfulness、Relevancy 和延迟的可复现评测。 |
| 7:20–8:00 | 展示迁移与测试命令。 | 强调工具受限、历史迁移兼容以及 SSE 合约测试。 |

## 面试追问提示

- **为何不用通用 Agent 工具？** 为保证答案只能依赖当前用户的本地知识库，降低外部信息、数据外发和提示注入风险。
- **如何定位幻觉？** 对照最终上下文、来源片段和 `citation_validation`；无效引用不能视为正确答案。
- **如何优化召回？** 先用固定评测集测 Recall@K/Hit Rate，再分开调分块、查询改写、Top-K 和阈值。
- **如何保证删除一致性？** 删除知识库前清理相应 Chroma collection，并用单元测试验证调用顺序。
