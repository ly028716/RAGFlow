- [本地 RAG Agent 功能修改实施方案](./本地RAG-Agent功能修改实施方案.md)

- `Web Scraper功能测试报告.md`、`手动验收测试清单.md`、`性能优化*.md`：历史网页采集材料。

当前 Agent 只包含查询改写、知识库检索、上下文选择和引用校验；不提供 OpenClaw、网页采集、外部搜索或通用工具调用。

## 迁移历史例外

迁移 `009` 至 `011` 必须保留，以让既有数据库可顺序升级。`012_remove_openclaw_tables` 仅清理 OpenClaw 历史表；历史 Web Scraper 表及数据不被删除，也不会暴露为当前运行时功能。
